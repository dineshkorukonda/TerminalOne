# Terminal One identity

The owner selected concept B, the T1 Monogram, on 2026-10-20 (#81). The cyan geometric T and numeral 1 share a diagonal negative-space cut on a charcoal rounded square. This is original Terminal One artwork, distributed under the repository's MIT license.

- `terminal-one.png`: transparent RGBA master generated with the built-in image generation tool.
- `terminal-one.ico`: Windows export with 16, 20, 24, 32, 40, 48, 64, 128 and 256px entries. Exporting resamples the master; it does not alter the design.

The main process supplies the window icon path; electron-builder embeds the ICO into the executable and NSIS installer/uninstaller. Shell profile icons remain separate.

Final generation prompt, using the selected concept board as the edit reference:

> Extract the chosen B T1 Monogram from this reference into ONE production app icon. Preserve the exact geometric cyan T and numeral 1 monogram with diagonal negative-space slash, on its charcoal rounded-square tile. A single large centered tile fills about 92% of the square canvas; transparent alpha outside the rounded tile. Flat crisp vector-like shapes, flat cyan, flat charcoal. No white board, no wordmark, no caption, no miniatures, no shadow, no added elements. Keep the reference monogram geometry and proportions. This will be exported to Windows ICO at multiple sizes.
